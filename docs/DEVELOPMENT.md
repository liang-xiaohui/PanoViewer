# Development notes

This document contains implementation and maintenance details for contributors. User-facing instructions belong in the root README.

## Project layout

- `src/viewer_source.html`: viewer source and UI
- `vendor/three.min.js`: vendored three.js r128
- `scripts/build.py`: assembles the standalone HTML
- `scripts/build_windows.ps1`: builds the Windows executable
- `scripts/windows/PanoViewer.cs`: native Windows launcher
- `tools/test_pano.png`: projection and seam test image
- `VERSION`: single source of truth for the application version

## Build and verification

```powershell
py -3 scripts\build.py --embed tools\test_pano.png
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

Verify that all placeholders are absent from release artifacts; the HTML opens offline; the EXE accepts its picker and command-line file paths; all four modes render correctly; seams are clean; and dragging, zooming, projection lock, and screenshots work.

## Projection implementation

The viewer layers three render paths and cross-fades them during mode changes: an inward-facing sphere for the unfolded view and polar background, a polar-projection disc for tiny-planet and tunnel views, and an outward-facing sphere for the crystal-globe view.

The polar disc uses analytic linear UVs generated by the mesh. Do not reconstruct UVs with `atan`/`asin` in a fragment shader: the longitude discontinuity can create a visible seam and incorrect mipmap derivatives. Panorama textures use `RepeatWrapping`, maximum available anisotropy, and a power-of-two canvas for WebGL 1 compatibility.

## Versioning and releases

The project follows Semantic Versioning. Update `VERSION`, rebuild and test both artifacts, then create a tag named `vX.Y.Z`. Release files are `PanoViewer-Windows-x64.exe` and `PanoViewer-Standalone.html`. Include SHA-256 checksums with every release.

The GitHub Actions release workflow supports optional Windows Authenticode signing. See [CODE_SIGNING.md](CODE_SIGNING.md) for secret names and certificate handling.

## macOS launcher

The optional macOS drag-and-drop app is compiled from `scripts/pano_applet.applescript`. It injects the selected image as a data URL into the built template and opens a temporary HTML file in the default browser.
